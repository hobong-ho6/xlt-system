# XLT System v3.0 - 웹 인터페이스 서비스 기획서

**서비스명**: XLT System Web Interface  
**버전**: 3.0  
**작성일**: 2026-04-22  
**대상**: DropWeb 정적 호스팅 + 로컬 백엔드 연동

---

## 1. 서비스 개요

### 서비스 목적
- 피그마 디자인 파일에서 텍스트를 자동 추출하고 5개 언어로 번역하는 웹 서비스
- 게임 및 앱 UI 로컬라이제이션 작업 효율성 향상
- 비개발자도 쉽게 사용할 수 있는 직관적인 웹 인터페이스 제공

### 타겟 사용자
- **1차**: UI/UX 기획자, 게임 기획자
- **2차**: 번역/로컬라이제이션 담당자
- **3차**: 프론트엔드 개발자

### 핵심 가치
- **자동화**: 수동 텍스트 추출 작업을 95% 줄임
- **정확성**: OCR + AI 번역으로 높은 품질의 다국어 번역 제공
- **효율성**: 피그마 URL 입력만으로 완전한 번역 Excel 파일 생성

---

## 2. 페이지 구성 (사이트맵)

```
XLT System Web Interface (SPA)
└── index.html (메인 페이지)
    ├── 연결 상태 확인 섹션
    ├── 피그마 URL 입력 섹션
    ├── OCR 처리 진행 상태 섹션
    ├── 텍스트 선택 섹션
    └── 번역 미리보기 팝업
```

### 페이지 역할
- **단일 페이지 애플리케이션(SPA)**: 전체 작업 플로우가 한 페이지에서 진행
- **실시간 상태 업데이트**: 각 단계별 진행 상황을 시각적으로 표시
- **반응형 디자인**: 데스크톱과 모바일 모두 지원

## 3. 페이지별 상세 기능

### 3.1 연결 상태 확인 영역
**목적**: 로컬 XLT 서버(localhost:5004) 연결 상태 실시간 확인

**UI 요소**:
- 연결 확인 중: 파란색 로딩 스피너 + "로컬 XLT 서버 연결 확인 중..."
- 연결 성공: 초록색 체크 아이콘 + "XLT 서버 연결됨 (localhost:5004)"
- 연결 실패: 빨간색 경고 아이콘 + 서버 시작 가이드

**동작**:
- 페이지 로드 시 자동으로 `http://localhost:5004/api/health` 호출
- 연결 실패 시 서버 시작 방법 단계별 안내 표시
- 연결 성공 시에만 메인 인터페이스 활성화

### 3.2 피그마 URL 입력 영역
**목적**: 사용자가 번역하고 싶은 피그마 디자인 URL 입력

**UI 요소**:
- 텍스트 입력 필드: placeholder "https://www.figma.com/design/..."
- OCR 처리 버튼: 파란색 "OCR 처리" 버튼
- Enter 키 지원: 입력 필드에서 Enter 키로도 처리 시작

**동작**:
- URL 유효성 검사: figma.com 포함 여부 확인
- 처리 중 버튼 비활성화 및 로딩 상태 표시
- 백엔드 `/upload` API 호출하여 피그마 이미지 다운로드 및 OCR 시작

### 3.3 처리 상태 표시 영역
**목적**: OCR 처리 진행 상황을 사용자에게 실시간으로 알림

**UI 요소**:
- 진행 상태 메시지: "피그마 이미지를 다운로드하고 있습니다..." → "텍스트를 추출하고 있습니다..."
- 로딩 스피너: 파란색 회전 애니메이션
- 처리 중에만 표시, 완료/실패 시 숨김

**동작**:
- 단계별 메시지 업데이트
- 처리 완료 시 자동으로 다음 섹션(텍스트 선택) 표시

### 3.4 텍스트 선택 영역
**목적**: OCR로 추출된 텍스트 목록에서 번역할 항목들을 사용자가 선택

**UI 요소**:
- 텍스트 목록: 체크박스 + 좌표 정보 + 추출된 텍스트
- 전체 선택/해제 버튼: 한번에 모든 항목 토글
- 번역 시작 버튼: 초록색 "번역 시작" 버튼

**동작**:
- 체크박스 선택/해제로 번역 대상 텍스트 지정
- 선택된 항목이 없으면 번역 버튼 클릭 시 경고 표시
- 번역 시작 시 백엔드 `/translate-selected` API 호출

### 3.5 번역 미리보기 팝업
**목적**: 번역 완료된 결과를 Excel 다운로드 전에 미리 확인

**UI 요소**:
- 새 창 팝업: 800x600 크기의 별도 창
- 항목별 카드: 원본 텍스트 + 처리된 텍스트 + 5개 언어 번역 결과
- Excel 다운로드 버튼: 초록색 "📊 Excel 파일 다운로드" 버튼

**동작**:
- 번역 완료 시 자동으로 팝업 창 열림
- 언어별 번역 결과 시각적으로 구분하여 표시
- 다운로드 버튼 클릭 시 Excel 파일 즉시 다운로드

## 4. 데이터 구조

### 4.1 입력 데이터
```json
{
  "figma_url": "https://www.figma.com/design/...",
  "session_id": "web-1234567890-abc123"
}
```

### 4.2 OCR 결과 데이터
```json
{
  "ocr_results": [
    {
      "index": 0,
      "text": "시작하기",
      "x": 100,
      "y": 200
    }
  ]
}
```

### 4.3 번역 요청 데이터
```json
{
  "session_id": "web-1234567890-abc123",
  "selected_indices": [0, 1, 2],
  "selected_texts": ["시작하기", "설정", "도움말"],
  "xlt_keys": ["item_1", "item_2", "item_3"]
}
```

### 4.4 번역 결과 데이터
```json
{
  "translations": [
    {
      "key": "item_1",
      "original": "시작하기",
      "processed": "시작하기",
      "ko_KR": "시작하기",
      "en_US": "Get Started",
      "ja_JP": "始める",
      "zh_TW": "開始使用",
      "th_TH": "เริ่มต้นใช้งาน"
    }
  ]
}
```

## 6. 외부 연동

### 6.1 CDN 서비스
- **Tailwind CSS**: https://cdn.tailwindcss.com (UI 프레임워크)
- **Font Loading**: 시스템 기본 폰트 사용 (외부 폰트 없음)

### 6.2 로컬 백엔드 API
- **Base URL**: http://localhost:5004
- **Health Check**: GET /api/health
- **File Upload**: POST /upload
- **OCR Results**: GET /select_texts
- **Translation**: POST /translate-selected
- **Excel Download**: POST /download-excel

### 6.3 CORS 설정
- 백엔드에서 Access-Control-Allow-Origin: * 설정 필요
- 브라우저 Mixed Content 정책 고려 (HTTPS → HTTP 호출)

## 8. 기술적 제약사항

### 8.1 DropWeb 제약
- **정적 파일만**: Python, PHP 등 서버 실행 파일 업로드 불가
- **파일 크기**: 최대 150MB (ZIP 압축 상태)
- **상대 경로**: 모든 링크와 리소스는 상대 경로 사용 필수

### 8.2 브라우저 호환성
- **CORS 정책**: 로컬 서버 접근 시 CORS 헤더 필요
- **Mixed Content**: HTTPS 사이트에서 HTTP 로컬 서버 호출 제한
- **팝업 차단**: 번역 미리보기 새 창이 차단될 수 있음

### 8.3 사용자 환경 요구사항
- **로컬 서버**: XLT 시스템이 localhost:5004에서 실행 중이어야 함
- **브라우저**: Chrome, Firefox, Safari 최신 버전 권장
- **네트워크**: 로컬 서버 접근을 위한 방화벽 설정 필요할 수 있음
