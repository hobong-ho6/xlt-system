# 🚀 XLT System v3.0 Installation Guide

**Figma Design → Multi-language Translation Automation Tool**

## 🌟 **Method 1: Smart Installation** (Recommended)

### 📱 **File Download Method** (For Beginners)

1. **📁 Download Installation File**:
   - Go to: https://github.com/hobong-ho6/xlt-system/blob/main/install/install_smart_update.command
   - Click **"Download raw file"** button (↓ icon)
   - Or **Right-click** → **"Save Link As"** on this link:
     ```
     https://github.com/hobong-ho6/xlt-system/raw/main/install/install_smart_update.command
     ```

2. **🖱️ Double-click to Execute**:
   - Double-click the downloaded `install_smart_update.command` file
   - If "Developer cannot be verified" warning → **Right-click → "Open"**

3. **⏰ Wait for Auto Installation** (10-15 minutes):
   ```
   🔍 Checking versions...
   📱 Local version: 0.0.0
   🌐 Latest version: 3.0.0

   🆕 New XLT System installation
   Proceed with installation? (Y/n): Y
   ```

4. **🎉 Use Immediately After Completion**:
   - Desktop shortcut **"XLT System.command"** created
   - Web browser auto-opens: `http://localhost:5004`

## ⚡ **Method 2: One-line Terminal Installation** (Advanced Users)

### 💻 **In Terminal**:

```bash
curl -O https://raw.githubusercontent.com/hobong-ho6/xlt-system/main/install/install_smart_update.command && chmod +x install_smart_update.command && ./install_smart_update.command
```

**Usage**:
1. **Open Terminal** (⌘ + Space → type "terminal")
2. **Copy & paste** above command
3. **Press Enter** → Auto installation begins
