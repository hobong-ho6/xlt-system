## 🎯 **빠른 시작**

### 🌟 **대부분의 사용자** (권장)
1. **`install_mac_complete_auto.command`** 더블클릭
2. 10-15분 대기 (대부분 자동, 몇 번만 선택)
3. 완료!

### 💻 **개발자** (Python 이미 있음)
1. **`install_mac.command`** 더블클릭
2. 2-3분 대기
3. 완료!

### 🔍 **설치 전 확인하고 싶다면**
1. **`check_system_mac.command`** 더블클릭 (선택사항)
2. 호환성 확인 후 설치 스크립트 실행

### 📂 **중요: 설치 위치**
- 이 `install` 폴더의 설치 스크립트들은 자동으로 올바른 위치에서 실행됩니다
- **어떤 설치 스크립트든 더블클릭만 하면** 자동으로 상위 디렉토리(`XLTTT`)로 이동하여 설치를 진행합니다
- 따라서 **`install` 폴더 안에서 직접 더블클릭**해도 안전합니다!

## 📋 **각 설치 방식 상세**

### 🌟 **완전 자동 설치** (`install_mac_complete_auto.command`)
**자동 설치되는 모든 컴포넌트**:
- ✅ **Xcode Command Line Tools** (개발 도구)
- ✅ **Python 3.8+** (3가지 방법 중 선택)
- ✅ **Git** (버전 관리, 선택적)
- ✅ **Homebrew** (패키지 관리, 필요시)
- ✅ **모든 Python 패키지** (다중 전략으로 안전)
- ✅ **고급 시스템 체크** (성능 분석, 네트워크 진단)

**적합한 사용자**: 🌟 **모든 사용자** (특히 처음 사용자)

### 🐍 **Python 자동 설치** (`install_mac_auto_python.command`)
**자동 설치되는 컴포넌트**:
- ✅ **Python 3.8+** (3가지 방법 중 선택)
- ✅ **XLT System 패키지** (기본)

**적합한 사용자**: Python이 없는 일반 사용자

### ⚡ **기본 설치** (`install_mac.command`)
**설치되는 컴포넌트**:
- ✅ **XLT System 패키지** (최소)

**사전 요구사항**: Python 3.8+ 설치 필수
**적합한 사용자**: 개발자, 고급 사용자

### 🔍 **시스템 체크** (`check_system_mac.command`)
**체크 항목**:
- macOS 버전 (10.15+)
- Python 설치 상태 (3.8+)
- pip 패키지 관리자
- 인터넷 연결
- 저장공간 (2GB+)
- 기본 라이브러리

## 🛠️ **설치 후 실행 방법**

설치가 완료되면 데스크톱에 바로가기가 생성됩니다:

### 📁 **데스크톱 바로가기**
- **`XLT System.command`** - 메인 웹 서버 실행
- **`XLT System (Tray).command`** - 시스템 트레이 앱 (선택 시)

### 🌐 **웹 인터페이스**
1. 바로가기 더블클릭
2. 웹 브라우저 자동 접속: `http://localhost:5004`
3. Figma URL 입력하여 번역 시작!

## ⚠️ **문제 해결**

### 🚫 **"개발자를 확인할 수 없음" 경고**
**해결**: 파일 **우클릭** → **"열기"** 선택

### 📱 **권한 요청**
- **접근성 권한**: 시스템 트레이 앱용
- **네트워크 권한**: 번역 API 사용
- 모두 **"허용"** 선택

### ⏳ **설치 시간**
- **완전 자동**: 10-15분 (정상)
- **Python 자동**: 5-8분 (정상)
- **기본 설치**: 2-3분 (정상)

### 🌐 **네트워크 문제**
- Wi-Fi 연결 확인
- 방화벽 설정 확인
- VPN 연결 상태 확인
