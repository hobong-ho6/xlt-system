## 🌟 **시스템 소개**

**XLT System v3.0**은 Figma 디자인에서 텍스트를 자동으로 추출하고 5개 언어로 번역하여 Excel 파일로 제공하는 전문 번역 시스템입니다.

### ✨ **주요 기능**
- 🎨 **Figma 전용**: Figma 디자인 URL에서 직접 텍스트 추출
- 🤖 **OCR 엔진**: EasyOCR 기반 정확한 텍스트 인식
- 🌐 **5개국 번역**: 한국어, 영어, 일본어, 중국어(번체), 태국어
- 🔧 **치환자 처리**: {{0}}, {{1}} 등 변수 자동 인식 및 처리
- 👀 **번역 미리보기**: Excel 다운로드 전 결과 확인
- 📊 **Excel 출력**: 표준 형식의 번역 결과 파일

### 🎯 **지원 언어**
| 언어 | 코드 | 특징 |
|------|------|------|
| 한국어 | ko_KR | 원본 언어 (번역 안함) |
| 영어 | en_US | Google Translate |
| 일본어 | ja_JP | Google Translate |
| 중국어(번체) | zh_TW | Google Translate |
| 태국어 | th_TH | Google Translate |

## 🚀 **시작하기**

### 1️⃣ **시스템 접속**

**📸 스크린샷 필요**: 브라우저 주소창에 `http://localhost:5004` 입력하는 모습

1. **웹 브라우저** 열기 (Chrome, Safari, Firefox 등)
2. **주소창**에 `http://localhost:5004` 입력
3. **Enter** 키 누르기

### 2️⃣ **메인 화면 구성**

**📸 스크린샷 필요**: XLT System 메인 화면 전체 모습

메인 화면에서 확인할 요소들:

- **🎯 헤더**: "XLT System v3.0" 타이틀과 설정 버튼
- **📊 시스템 상태**: 모든 컴포넌트 정상 작동 확인
- **📑 탭 메뉴**: "텍스트 번역"과 "엑셀 합치기" 2개 탭
- **🔵 상태 표시**: 파란색이면 정상, 빨간색이면 문제 있음

### 3️⃣ **시스템 상태 확인**

정상 작동 시 다음과 같이 표시됩니다:
```
✅ 시스템 정상 작동 중
• OCR 엔진 정상
• 번역 시스템 정상  
• Figma API 연결 정상
• 파일 시스템 정상
```

## 🎨 **메인 기능: 텍스트 번역**

### **Step 1: Figma URL 입력**

**📸 스크린샷 필요**: Figma URL 입력창과 "번역 시작" 버튼

1. **"텍스트 번역" 탭** 클릭 (기본으로 선택됨)
2. **피그마 URL 입력창**에 Figma 디자인 링크 붙여넣기
   ```
   예시: https://figma.com/design/XXXXXXXX/project-name?node-id=123-456
   ```
3. **"번역 시작" 버튼** 클릭

### **Step 2: OCR 처리 및 텍스트 추출**

**📸 스크린샷 필요**: OCR 진행 상황과 로딩 화면

시스템이 자동으로 다음 작업을 진행합니다:
- 📥 Figma 이미지 다운로드
- 🔍 OCR 텍스트 추출
- 🔧 노이즈 필터링
- 📝 의미있는 텍스트만 선별

### **Step 3: 텍스트 선택**

**📸 스크린샷 필요**: OCR 결과 페이지에서 텍스트 목록과 체크박스들

OCR 결과 페이지에서:

1. **📋 추출된 텍스트 목록** 확인
   - 각 텍스트는 **Y좌표 순서**로 표시 (위에서 아래로)
   - **신뢰도 점수** 표시 (높을수록 정확)
   - **원본 텍스트** 및 **교정된 텍스트** 모두 표시

2. **☑️ 번역할 텍스트 선택**
   - 체크박스 클릭으로 개별 선택
   - "전체 선택/해제" 버튼으로 일괄 처리
   - **선택된 항목 수** 실시간 표시

3. **✏️ 텍스트 수정 (필요시)**
   - OCR이 잘못 인식한 텍스트 직접 수정 가능
   - 클릭해서 편집 모드로 전환

### **Step 4: 치환자 설정**

**📸 스크린샷 필요**: 치환자 설정 모달 창

시스템이 자동으로 치환자 패턴을 감지하면 모달창이 나타납니다:

**🔍 자동 감지 패턴**:
- 숫자: `3일`, `5개`, `100원`
- 금액: `1,000 USDT`, `500 USD`
- 레벨: `레벨 5`, `LV.10`
- 퍼센트: `15%`, `0.5%`

**설정 방법**:
1. **감지된 패턴 확인**
2. **치환자 적용할 텍스트** 체크박스로 선택
3. **{{0}}, {{1}} 순서**로 자동 할당
4. **"적용" 버튼** 클릭

### **Step 5: 번역 실행**

**📸 스크린샷 필요**: 번역 진행률 표시 화면

1. **"선택된 텍스트 번역" 버튼** 클릭
2. **번역 진행률** 실시간 확인
   - 각 언어별 진행 상황 표시
   - 예상 소요 시간 표시
   - 에러 발생 시 재시도 기능

### **Step 6: 번역 미리보기**

**📸 스크린샷 필요**: 번역 결과 미리보기 모달

번역 완료 후 **미리보기 모달**에서 확인:

- **📋 XLT 키**: 고유 식별자
- **🔤 원본 텍스트**: 선택한 원본 텍스트
- **🔧 처리된 텍스트**: 치환자가 적용된 텍스트
- **🌐 5개국 번역 결과**: 
  - 🇰🇷 한국어 (원본)
  - 🇺🇸 영어
  - 🇯🇵 일본어  
  - 🇨🇳 중국어(번체)
  - 🇹🇭 태국어

### **Step 7: Excel 다운로드**

**📸 스크린샷 필요**: 다운로드 확인 대화상자

1. **번역 결과 확인** 후 **"Excel 다운로드" 버튼** 클릭
2. **파일 저장 위치** 선택
3. **Excel 파일 생성 완료**

**📄 Excel 파일 구조**:
```
Key ID | en_US | ko_KR | ja_JP | zh_CN | zh_TW | vi_VN | tr_TR | ru_RU | de_DE | th_TH | fr_FR | ms_MY | id_ID | ar_AA | pt_BR | pt_PT | it_IT | es_419 | es_ES
```

## 📊 **추가 기능: 엑셀 합치기**

여러 번역 프로젝트의 Excel 파일을 하나로 통합하는 기능입니다.

### **Step 1: 엑셀 합치기 탭**

**📸 스크린샷 필요**: 엑셀 합치기 탭 화면

1. **"엑셀 합치기" 탭** 클릭
2. **파일 업로드 영역** 확인

### **Step 2: 파일 선택**

**📸 스크린샷 필요**: 파일 선택 대화상자

1. **"Excel 파일 선택" 버튼** 클릭
2. **여러 .xlsx 파일** 동시 선택 (Ctrl/Cmd + 클릭)
3. **선택된 파일 목록** 확인

### **Step 3: 파일 합치기**

**📸 스크린샷 필요**: 합치기 진행 화면과 결과

1. **"파일 합치기" 버튼** 클릭
2. **처리 진행률** 확인
3. **통합된 Excel 파일** 자동 다운로드

### 🔧 **시스템 설정**

**📸 스크린샷 필요**: 설정 페이지 화면

우측 상단 **"설정" 버튼** 클릭으로 접근:

- **📊 시스템 상태**: 모든 컴포넌트 상태 확인

- **📝 로그 보기**: 시스템 로그 확인

### 🎯 **Figma 설정**

**피그마 개인 액세스 토큰 설정** (필수):

1. **Figma 계정** → **Settings** → **Personal access tokens**
2. **새 토큰 생성** → 권한 설정
3. **토큰을 figma_config.json에 저장** 또는 **환경변수 설정**

### 📊 **번역 품질 최적화**

**한국어 텍스트 교정**:
- 시스템이 자동으로 OCR 오류 교정
- `이울` → `이율`, `미선` → `미션` 등

**번역 일관성**:
- Unifi 금융 서비스용 전문 용어 사전 내장
- `guide.md` 파일 기반 번역 가이드라인 적용

## 🚨 **문제 해결**

### ❌ **일반적인 오류**

**1. "시스템 연결 실패"**
```
해결방법:
1. 브라우저 새로고침 (F5)
2. http://localhost:5004 주소 재확인
3. XLT System 서버 재시작
```

**2. "Figma 이미지 로드 실패"**
```
해결방법:
1. Figma URL 형식 확인
2. Figma 파일 공개 설정 확인  
3. Figma 개인 액세스 토큰 설정 확인
```

**3. "OCR 결과 없음"**
```
해결방법:
1. 이미지에 명확한 텍스트가 있는지 확인
2. 텍스트 크기가 너무 작지 않은지 확인
3. 이미지 화질이 충분한지 확인
```

**4. "번역 실패"**
```
해결방법:
1. 인터넷 연결 상태 확인
2. 태국어 번역 시 시간 충분히 대기
3. 텍스트를 작은 단위로 나누어 번역
```

**5. "Excel 다운로드 실패"**
```
해결방법:
1. 브라우저 팝업 차단 해제
2. 브라우저 캐시 삭제 후 재시도
3. 브라우저 강제 새로고침 (Ctrl/Cmd + Shift + R)
```

### 🔧 **고급 문제 해결**

**서버 포트 충돌**:
```bash
# 터미널에서 기존 서버 종료
pkill -f stable_web_server.py

# 포트 사용 확인
lsof -i :5004
```

**메모리 부족**:
```
- 큰 이미지는 분할해서 처리
- 브라우저 탭 정리
- 시스템 재시작
```

## 💡 **팁과 주의사항**

### ✅ **최적 사용법**

**1. Figma URL 준비**
- 공개 또는 공유 링크 사용
- 특정 노드 ID 포함 권장
- 텍스트가 명확히 보이는 화면 선택

**2. 텍스트 선택 요령**
- 의미 있는 텍스트만 선택
- UI 라벨이나 버튼 텍스트 우선
- 중복 텍스트는 하나만 선택

**3. 치환자 활용**
- 숫자, 금액은 치환자 적용 권장
- 일관성 있는 변수명 사용
- 번역 후에도 동일한 형태 유지

**4. 번역 품질 관리**
- 미리보기에서 반드시 검토
- 전문 용어는 원본 유지 고려
- 문맥에 맞는 번역인지 확인

### ⚠️ **주의사항**

**보안**:
- Figma 토큰은 외부에 노출 금지
- 민감한 정보가 포함된 디자인 주의
- 사내 전용 네트워크에서 사용 권장

**성능**:
- 대용량 이미지는 처리 시간 증가
- 동시에 여러 번역 작업 지양
- 정기적인 시스템 재시작 권장

**파일 관리**:
- Excel 파일명에 날짜/버전 포함 권장
- 정기적인 백업 수행
- 번역 결과 검토 후 최종 사용
