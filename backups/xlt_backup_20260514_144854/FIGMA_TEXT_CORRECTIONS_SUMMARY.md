# 피그마 텍스트 추출 교정 시스템 개선 요약

## 문제점 분석
사용자가 제공한 피그마 URL에서 발견된 주요 문제점들:
1. **띄어쓰기 오류**: "어떻게이 율을" → "어떻게 이율을" 
2. **치환자 조기 적용**: "최대 연 {{0}} + {{1}}" (본래 "최대 연 5년 4.8%"이어야 함)
3. **교정 전/후 비교 표시 부족**: 사용자가 어떤 교정이 이루어졌는지 확인 어려움

## 구현된 해결책

### 1. 교정 사전 확장 (`xlt/core/config.py`)
```python
# 추가된 띄어쓰기 교정 패턴들
'어떻게이 율을': '어떻게 이율을',
'어떻게이율을': '어떻게 이율을',
'달러와 같은가 치를가진': '달러와 같은 가치를 가진',
'최대연': '최대 연',
'가 치를': '가치를',
'이 율': '이율',
'혜 택': '혜택'
# ... 및 다수의 세부 패턴들
```

### 2. 원본 텍스트 보존 (`stable_web_server.py`)
```python
# 피그마 텍스트 처리 시 원본 보존
result['original_text'] = original_text  # 교정 전 원본
result['text'] = corrected_text          # 교정 후 텍스트
result['corrected'] = original_text != corrected_text  # 교정 여부
```

### 3. 교정 전/후 비교 UI (`templates/ocr_results.html`)
- **교정된 텍스트**: 교정 전후 비교 박스 표시
- **원본 텍스트**: 교정이 없었던 경우와 구분
- **시각적 표시**: 
  - ❌ 교정 전: ~~원본 텍스트~~ (취소선)
  - ✅ 교정 후: **교정된 텍스트** (굵은 글씨)

### 4. 교정 시스템 우선순위 개선 (`stable_web_server.py`)
config.py의 최신 교정 사전을 우선 적용하도록 수정하여 일관성 확보

## 치환자 조기 적용 문제 분석

치환자는 **텍스트 선택 후** `/check-placeholders` 엔드포인트에서 처리되므로, 초기 추출 단계에서는 적용되지 않아야 합니다.

**올바른 처리 순서**:
1. 피그마 텍스트 노드 추출 → "최대 연 5년 4.8% APR"
2. 한국어 교정 적용 → "최대 연 5년 4.8% APR" (변화없음, 이미 올바름)
3. 사용자 텍스트 선택 
4. 치환자 패턴 검사 → "최대 연 {{0}} {{1}}% APR"

## 검증 방법

1. **웹 서버 실행**: `python3 stable_web_server.py`
2. **브라우저 접속**: `http://localhost:5004`
3. **피그마 URL 테스트**: 제공해주신 URL 입력
   ```
   https://www.figma.com/design/qy27FqeZejn3futUxH7QIP/16.-Mission---Reward?node-id=228-6519&t=7UlHTDuTYnTA5jvk-1
   ```
4. **교정 전/후 비교 확인**: 텍스트 선택 화면에서 교정 박스 표시 확인
5. **치환자 적용 시점 확인**: 치환자는 텍스트 선택 후에만 적용되는지 확인

## 기대 효과

- **정확한 띄어쓰기**: "어떻게이 율을" → "어떻게 이율을" 자동 교정
- **투명성 향상**: 교정 전/후 명확한 비교 표시
- **치환자 처리 개선**: 적절한 시점에서만 치환자 적용
- **사용자 신뢰도 증대**: 어떤 변경이 이루어졌는지 명확히 확인 가능
