## 🌟 **시스템 소개**

**XLT System v3.3**는 Figma 디자인에서 텍스트를 자동으로 추출하고 **맞춤법/띄어쓰기를 자동 교정**한 후 **Unifi 전문 용어 데이터베이스**를 활용하여 5개 언어로 번역하는 **macOS 네이티브 트레이** 기반 번역 시스템입니다.

### 🆕 **v3.3 신규 기능 (2026-04-27)**

#### ✨ **맞춤법/띄어쓰기 3단계 자동 교정**
- **1단계 OCR 특화 사전**: 20+ 오인식 패턴 ("이울→이율", "미선→미션")
- **2단계 바른 AI API**: api.bareun.ai 맞춤법 검사기 통합
- **3단계 정규표현식**: 조사 띄어쓰기 등 최종 정리
- **자동 학습 캐시**: 한번 교정된 내용은 자동 저장 (0.007초 vs 1-2초)
- **적용 시점**: 이미지 업로드 직후 OCR 결과에 즉시 적용

#### 🔍 **맞춤법 검사 버튼**
- **각 텍스트 옆 검사 버튼**: 사용자가 수정한 텍스트를 재검사
- **실시간 교정**: 바른 AI API로 즉시 교정
- **시각적 피드백**: 로딩 스피너 + 녹색 깜빡임 + 알림 메시지

#### 📚 **사용자 교정 학습 시스템**
- **번역 시작 시 자동 학습**: OCR 원본 ↔ 사용자 수정 매핑
- **다음 사용 시 적용**: 학습된 교정 내용 자동 적용
- **학습 로그**: 세션 로그에 학습 내역 표시

#### 🔧 **XLT Key 단순 생성 모드**
- **2가지 키 생성 방식**: 지능형 vs 단순 prefix + 번호
- **사용자 정의 prefix**: MY_KEY_001, MY_KEY_002 형태
- **모달에서 선택**: 번역 전 키 생성 방식 선택 가능

### ✨ **v3.1-3.2 핵심 기능 (계속 지원)**

#### 🏆 **Unifi 전문 번역 시스템**

#### 🖥️ **macOS 네이티브 트레이 시스템**

#### 🔄 **자동 업데이트 시스템**

## 🚀 **시작하기**

### 1️⃣ **설치 완료 후 첫 시작**

**v3.1 완전 자동화 설치**:
```bash
curl -sL https://raw.githubusercontent.com/hobong-ho6/xlt-system/main/install/install_v2.sh | bash
```

### 2️⃣ **트레이 시스템 시작**

설치 완료 후 데스크톱에 생성된 바로가기를 실행:

1. **데스크톱**에서 **"XLT System (Tray).command"** 더블클릭
2. **🎯 시스템 트레이**에 XLT 아이콘 확인 (상단 메뉴바 오른쪽)
3. **터미널 자동 종료** (15초 후 또는 즉시 종료 선택)
4. **브라우저 자동 접속**: `http://localhost:5004`

### 3️⃣ **시스템 접속 (수동)**

트레이가 실행된 후 수동으로 웹 인터페이스 접속:

<img width="376" height="63" alt="image" src="https://github.com/user-attachments/assets/03373390-3c09-4d95-9fd8-e6436ba5d005" />

1. **웹 브라우저** 열기 (Chrome, Safari, Firefox 등)
2. **주소창**에 `http://localhost:5004` 입력
3. **Enter** 키 누르기

### 4️⃣ **메인 화면 구성**

<img width="1435" height="986" alt="image" src="https://github.com/user-attachments/assets/795d96e4-1838-43e7-a8e2-4dc4a4bc8ed5" />

메인 화면에서 확인할 요소들:

- **🎯 헤더**: "XLT System v3.1" 타이틀과 설정 버튼
- **🔄 업데이트 알림**: 새 버전 있을 시 헤더에 업데이트 버튼 표시
- **📊 시스템 상태**: 모든 컴포넌트 정상 작동 확인
- **📑 탭 메뉴**: "텍스트 번역"과 "엑셀 합치기" 2개 탭

## 🖥️ **트레이 시스템 사용법**

### 🎯 **트레이 아이콘 확인**

시스템 시작 후 **상단 메뉴바 오른쪽**에서 XLT 아이콘 확인:
- **🟢 XLT System**: 서버 실행 중
- **🔴 XLT System**: 서버 중지됨

### 📋 **트레이 메뉴 구성**

트레이 아이콘 클릭 시 나타나는 메뉴:

```
🟢 XLT System
├─ XLT System 열기      ← 웹 인터페이스 실행
├─ ──────────────────
├─ 서버 시작           ← 웹서버 시작 (중지 시에만 표시)
├─ 서버 중지           ← 웹서버 중지 (실행 시에만 표시)
├─ 서버 재시작         ← 웹서버 재시작 (실행 시에만 표시)
├─ ──────────────────
├─ 로그 보기           ← 터미널에서 실시간 로그 확인
├─ 상태 확인           ← 시스템 정보 표시
└─ 종료               ← 트레이 앱 완전 종료
```

### ⚡ **주요 메뉴 기능**

#### **XLT System 열기**
- 기본 브라우저에서 `http://localhost:5004` 자동 실행
- 웹 인터페이스 즉시 접속

#### **서버 제어 (시작/중지/재시작)**
- **서버 시작**: 중지된 웹서버를 다시 시작
- **서버 중지**: 실행 중인 웹서버를 안전하게 종료
- **서버 재시작**: 중지 → 2초 대기 → 시작 (설정 변경 후 적용 시 유용)

#### **로그 보기** ⭐
- **터미널 자동 실행**: macOS 터미널 앱이 자동으로 열림
- **실시간 로그 스트리밍**: `tail -f server.log` 실행
- **컬러 로그**: 에러(빨간색), 성공(초록색), 정보(파란색) 구분
- **모든 작업 추적**: Figma 처리, OCR, 번역, Excel 생성 과정 실시간 확인

#### **상태 확인**
```

   • 포트: 5004
   • 상태: 🟢 실행 중
   • PID: 12345
   • URL: http://localhost:5004

📊 시스템 정보:
   • macOS: 14.0 (arm64)
   • Python: 3.9.6

   • 업타임: 2시간 15분

## 🆕 **v3.3 신규 기능**

### ✨ **맞춤법/띄어쓰기 3단계 자동 교정**

v3.3의 가장 큰 신규 기능입니다. 이미지 업로드 직후 OCR 결과에 자동으로 맞춤법/띄어쓰기 교정이 적용됩니다!

#### **교정 파이프라인**

**1단계: OCR 특화 사전** (즉시 교정)
- "이울" → "이율"
- "미선" → "미션"
- "토근" → "토큰"
- "모매일" → "매일"
- 20+ 오인식 패턴 자동 교정

**2단계: 바른 AI API** (api.bareun.ai)
- 한국어 맞춤법/띄어쓰기 전문 검사
- 자동 학습 캐시 시스템
  - 한번 교정된 내용은 `data/spelling_corrections.json`에 저장
  - 0.007초 (캐시) vs 1-2초 (API)
  - 80% 히트율

**3단계: 정규표현식 정리**
- 연속 공백 제거
- 조사 띄어쓰기 ("게임 을" → "게임을")
- 숫자 단위 ("10 개" → "10개")

#### **적용 시점**
```
이미지 업로드
    ↓
OCR 텍스트 추출
    ↓
✨ 자동 교정 (3단계 파이프라인)
    ↓
OCR 결과 페이지 표시 (교정된 텍스트)
```

#### **사용 예시**

**입력 (Figma 이미지)**:
```

```

**출력 (OCR 결과 페이지)**:
```

```

**교정 과정 (세션 로그)**:
```
🔤 교정: '일일미선달성완료' → '일일 미션 달성 완료'
