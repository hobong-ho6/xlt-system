설정 도움말
피그마 토큰이란?

XLT 시스템이 사용자의 피그마 파일에 접근하기 위한 인증 키입니다. 개인별로 발급받아야 하며, 타인과 공유하면 안 됩니다.

용어집 관리란?

LINE API를 통해 금융 용어의 번역 일관성을 보장합니다. 모든 용어는 실시간으로 동기화되어 번역 품질을 향상시킵니다.

보안 주의사항
  • 토큰을 다른 사람과 공유하지 마세요
  • 토큰이 유출되었다면 즉시 재발급하세요
  • 정기적으로 토큰을 갱신하는 것을 권장합니다
문제해결
  • 토큰 테스트 실패: 토큰을 다시 확인해보세요
  • 디렉토리 오류: 경로가 존재하고 쓰기 권한이 있는지 확인하세요
  • 포트 충돌: 다른 포트 번호로 변경해보세요
  • 용어집 연결 실패: LINE API 상태를 확인하거나 네트워크 연결을 점검하세요
